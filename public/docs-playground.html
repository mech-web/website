Validation

If patterns are non-exhaustive, the compiler reports missing variants and prevents the program from compiling, so you won't accidentally drop cases.

Tagged Unions

result := x? | .red => 0xFF0000 -- Forgot to cover :blue and :green cases, so this won't compile.
Error: MatchNonExhaustive — Match over enum color is non-exhaustive. Missing variants: :green, :blue.

Pattern Matching

Match arms should also return a compatible kind to prevent accidental type mismatches between branches.

<status> := :running | :pending | :stopped x := :running code := x? | :running => 1 | :pending => "pending" | :stopped => 0
