Mech is a programming system as well as a programming language. Its design includes the language’s type system and memory model, together with the ways programs are written, run, inspected, adapted, and shared. The technical dimensions framework[1]J. View paper provides a taxonomy for describing and comparing programming systems across this broader range of concerns. This page applies the framework to Mech through descriptions and working examples.
